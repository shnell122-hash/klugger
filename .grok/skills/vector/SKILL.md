# Vector Logo Refinement Skill

This skill refines logos by correcting the trazos (strokes), cleaning lines, making them crisp and high quality, vector style.

## Steps

1. Analyze the provided logo image or screenshot from the branding document.
2. Identify the main elements: the text "Klugger", any fox/zorro motifs, colors (green to blue gradient), minimalist style.
3. Use image editing to:
   - Correct and smooth the strokes and lines.
   - Remove noise, jagged edges, or imperfections.
   - Enhance clarity, make it look like a professional vector logo.
   - Preserve the branding: intelligence, audacia, security of the fox, degradado verde a azul, minimalista.
4. Output the refined logo as a high-quality image (PNG with transparency if possible).
5. Save the refined logo to the project assets folder for inclusion in the dashboard (e.g. in dashboard-financial/public or assets folder).
6. Update the dashboard TSX to include the refined logo image (e.g. in the header or hero section with <img> tag).

Use available image editing tools with precise prompts focused on stroke correction and quality enhancement.
