## Lo que se hizo esta sesión

### 1. Migración LLM del financial-bot — branch `migrate-llms-deepseek-gemini`

Se migraron todos los agentes del bot financiero de modelos caros a modelos eficientes:

| Agente | Antes | Después | Ahorro |
|--------|-------|---------|--------|
| `TransactionOrchestrator` | `claude-sonnet-4-6` | `deepseek-v4-pro` | ~75% |
| `VisionAgent` | `claude-haiku-4-5` | Gemini Flash → DeepSeek Flash | ~65% |
| `InvoiceAgent` | `deepseek-chat` (V3) | `deepseek-v4-pro` (V4) | ~70% |
| `ContextReader` | `deepseek-chat` (V3) | `deepseek-v4-pro` (V4) | ~70% |
| `ResponseGen` | `deepseek-chat` (V3) | `deepseek-v4-pro` (V4) | ~70% |

**Commits:** `ccb531d`, `0f80915`, `e9d30bd`, `30d55dd`, `cc5f0aa`
**Branch:** [`migrate-llms-deepseek-gemini`](https://github.com/vilarkptl-lang/agentic-repo/tree/migrate-llms-deepseek-gemini/financial/bot/agents)

**Esta migración aún NO está en `main`.** El servidor sigue corriendo los modelos viejos hasta que se aplique:
```bash
git checkout migrate-llms-deepseek-gemini -- financial/bot/agents/ financial/bot/financial-bot.js
pm2 restart financial-bot
```

### 2. Corrección crítica de costos — `relay/chat-agent.js` en `main`

**Problema:** Los modelos DeepSeek se enrutaban por LiteLLM → Sonnet (20× más caro de lo esperado).
**Fix:** `proxyModel: null` en los tres modelos DeepSeek para llamar directo a `api.deepseek.com`.

**Commits:** `eaec456`, `11d57ab`

### 4. Bridge Telethon → Relay — `financial/telethon-bridge.py`

Script Python que automatiza el ciclo:
**Test falla → dispatch al agente flujos → fix → restart bot → retest**

```bash
# Uso básico:
pytest financial/tests/ --tb=short 2>&1 | python3 financial/telethon-bridge.py --push

# Loop automático (reintenta hasta que pasen los tests):
./financial/run-telethon-tests.sh --loop --max 5
```

**Archivos:** [`financial/telethon-bridge.py`](https://github.com/vilarkptl-lang/agentic-repo/blob/claude/agent-monitoring-dashboard-4v8iq/financial/telethon-bridge.py) · [`financial/run-telethon-tests.sh`](https://github.com/vilarkptl-lang/agentic-repo/blob/claude/agent-monitoring-dashboard-4v8iq/financial/run-telethon-tests.sh)

### 5. Reglas anti-alucinación para el chat-agent (Telegram bot)

El bot en ia.vilarkptl.com tenía tres problemas graves:
- Usaba `ryby.lease` para tareas que no son de fiscalai
- Afirmaba que branches existían sin verificarlo
- Confundía `relay/workspaces/fiscalai/` con `financial/bot/`

Se añadieron reglas explícitas al system prompt del chat-agent.
**Commits:** `044713c`, `11d57ab`
